# 「RIME 键道」（KeyTao）码表检查器

## 🧭 用法

```text
keytao-dict-checker -s <单字码表>
keytao-dict-checker -p <词组码表>
keytao-dict-checker <单字码表> <词组码表>
```

| 单字检查项 | 说明                           | 输出 |
|------------|--------------------------------|------|
| 飞键       | 编码涉及飞键，但伴生不完整     | 词条 |
| 遗漏       | 单字遗漏简码或全码             | 词条 |
| 冗余       | 单字在单个编码链中存在多余词条 | 词条 |
| 空码       | 有词条跳过空闲的短码而使用长码 | 编码 |

| 词组检查项 | 说明                           | 输出 | 依赖单字 |
|------------|--------------------------------|------|----------|
| 飞键       | 编码涉及飞键，但伴生不完整     | 词条 | 是       |
| 错码       | 词组和编码在构词规则下无法自洽 | 词条 | 是       |
| 冗余       | 词组在单个编码链中存在多余词条 | 词条 | 否       |
| 空码       | 有词条跳过空闲的短码而使用长码 | 编码 | 否       |

按输入自动启用条件允许的全部检查项：仅提供单字码表时 4 项；仅提供词组码表时 2 项；两者齐备时 8 项。
