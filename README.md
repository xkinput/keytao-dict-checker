# 「RIME 键道」（KeyTao）码表检查器

## 🧭 用法

```text
keytao-dict-checker -s <单字码表>
keytao-dict-checker -p <词组码表>
keytao-dict-checker <单字码表> <词组码表>
```

| 单字检查项   | 说明                                   | 输出 |
|--------------|----------------------------------------|------|
| 编码形式异常 | 编码不是 `<2个音码><2-4个形码>` 的前缀 | 词条 |
| 形码段冲突   | 单字不同词条的形码不是单一形码段的前缀 | 词条 |
| 飞键伴生缺失 | 编码因飞键而须存在伴生编码，实则不存在 | 词条 |
| 简码缺失     | 单字在某编码链上只有全码词条           | 词条 |
| 简码冗余     | 单字在某编码链上有超过一个简码词条     | 词条 |
| 简码重码     | 被多个现有简码词条使用的编码           | 编码 |
| 简码空码     | 被现有简码词条跳过的空码               | 编码 |

| 词组检查项 | 说明                                                         | 输出 | 依赖单字 |
|------------|--------------------------------------------------------------|------|----------|
| 形式异常   | 编码不是 `<4个音码><2个形码>` 或 `<3个音码><3个形码>` 的前缀 | 词条 | 否       |

按输入自动启用条件允许的全部检查项：仅提供单字码表时 5 项；仅提供词组码表时 1 项；齐备时 6 项。
