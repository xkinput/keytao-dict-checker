# 「RIME 键道」词库检查器

## 🧭 用法

```sh
keytao-dict-checker <词库路径> [单字码表路径] [检查项]
```

| 参数             | 说明                                   |
|------------------|----------------------------------------|
| `<词库路径>`     | 被检词库。                             |
| `[单字码表路径]` | 用作参考的单字码表。不被依赖时可省略。 |

| 检查项 | 说明                                                                  |
|--------|-----------------------------------------------------------------------|
| `-i`   | 无法按规则用单字码表推导出该词组的该编码（Incorrect）。依赖单字码表。 |
| `-o`   | 词组编码包含飞键，但编码伴生存在遗漏（Omitted）。依赖单字码表。       |
| `-r`   | 该词组在单个编码链中存在冗余（Redundant）词条。                       |
| `-v`   | 该词组跳过了空闲（Vacant）的短码而使用了更长的编码。                  |

若不指定任何检查项，默认全部检查；若指定了任意项，则只检查指定项。
